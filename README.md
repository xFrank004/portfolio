# Portfolio · Franco Rodriguez Pouso

Portfolio personal hecho con React + Vite. Pantalla de entrada, hero con terminal animada, y secciones de perfil, stack, proyectos y contacto.

## Correr en local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

El resultado queda en `dist/`, listo para subir a Vercel o Netlify.

## Editar contenido

- Datos personales y stack: `src/data/profile.js`
- Proyectos: `src/data/projects.js`
